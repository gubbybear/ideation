Configurator

Phase 0: founders edit JSON. Phase 2+: CORE UI.

  • Ontology generator → builds the per-deployment ontology
  • Extraction-schema generator → seeds the classifier
  • Adapter wiring → configures each adapter
  • Eval-pack scaffolding → seeds the golden set
  • Compliance posture capture → sets the posture engine
  • Samples the object store for buyer history

Privacy & compliance

Wraps every payload that leaves the SMB boundary.

  • Compliance posture engine — Standard · Restricted · Air-gapped
  • PII detection + redaction — universal classes plus AU: TFN, ABN, ACN, Medicare, ATO refs, Centrelink CRN, state licences, passport, immigration case IDs
  • Inference router — AU-hosted by default; offshore requires sign-off
  • Guardrails — action permissions, residency, send approvals
  • Adapter sensitivity classification — in-tenant vs egress

Evals

Always on. Nightly + post-change. Gates autonomous actions.

  • Eval harness — samples live traffic + full golden set after every change
  • Golden set — per deployment, sourced from buyer history at config time
  • Failure-mode library — cross-deployment, fed by every red-band incident
  • Active-learning feedback to classifier + generation

Audit

Every inference + every write-back, logged.

  • Audit trail logger — collects from router, PII, review, adapters
  • Audit log store — append-only, scoped per deployment
  • Read surface — visible from the staff cockpit
  • Audit pack export — handed to the SMB's auditor or professional body

Inbound walkthrough — how one document moves through

1 · arrive SMB client emails three PDFs to the shared inbox. M365 OAuth in the SMB tenant.
2 · ingest Email adapter pulls the message + attachments into the unified inbound queue. Object store keeps the originals.
3 · classify + extract Few-shot classifier tags type and engagement; extraction pulls typed entities. PII pipeline redacts before any inference call.
4 · retrieve GraphRAG over the deployment ontology finds the matching engagement and surfaces missing-info gaps.
5 · generate Draft chase message + filed metadata. Inference router sends tokens to Bedrock Sydney or Azure AU East. Restored on return.
6 · review & act Staff approve in the cockpit. Reply goes out via email adapter; filed doc lands in PM system via REST adapter. Every step audited.
