Why monochrome

Reach is a white-label service.

CORE ships under each Dev's practice. STACK ships inside each SMB's branded workflow. The product surface defers so the client surface lands. Black and white stay out of the way of whoever is in the room. Colour earns its place only when it carries operational meaning — live, gate, value, evidence, failure.

Implication

Decorative brand colour belongs to the Dev and to the SMB. Reach contributes the structure, the rhythm, and the five reserved accents — nothing that competes with the practitioner or the deployment they are presenting.

Shared rules

The family resemblance.

One surface

CORE and STACK live on the same paper. The dark/light split goes away. What stays is the same component skeleton, the same line treatment, the same monochrome chrome.

Density carries mode

CORE feels like a console because rows compress, mono leads, numerals dominate. STACK feels like a deployment surface because rows breathe and semantic labels read in plain language.

Accents earn space

Five accents with five reserved meanings. If a colour is showing, it is telling the reader something operational. Brand colour for its own sake is gone.
